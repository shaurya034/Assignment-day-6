# Shaurya Pratap Singh — Profile Card Project

A responsive, single-file profile page built for the **Box Model, Display, Positioning** assignment. Open `index.html` in a browser to view it.

## Assignment features included

- Profile hero with layered decorative shapes using `position` and `z-index`.
- Three rounded card styles: light, dark, and accent.
- Sticky navigation bar and a fixed floating back-to-top button.
- A bounded notes panel with `overflow: auto`.
- A responsive horizontal tile strip whose overflow stays inside its panel.
- An annotated CSS box-model illustration showing content, padding, border, and margin.
- Responsive layouts for tablet and mobile widths, with `box-sizing: border-box` applied globally.
